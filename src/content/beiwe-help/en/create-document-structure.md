In Beiwe, each type of document the team writes in the patient records has a **structure**: a name and a list of **sections**. When someone writes the document, each section becomes a field to fill in, and the result is a well-organized PDF with the clinic's logo.

🎬 Video: [How to create different types of reports](https://www.youtube.com/watch?v=ZT7EXl9_Wb0) (in Portuguese)

## Report or diary?

| | Report | Diary |
|---|---|---|
| What it is for | a complete document, written in one go: session report, assessment, feedback report | short, frequent notes that add up over time: logbook, week-by-week progress notes |
| How it is saved | each report becomes a **signed PDF**, kept in the patient record under the date it was written | each note is a dated **entry**, added to the earlier entries of the same diary |
| Sections | you choose them all; at least one is required | the **Data** (date) section is required and fixed 🔒; the **Análise** (analysis) section is suggested and can be removed; you choose the rest |
| Where to find it | Patient Records → Saved Documents, one PDF per date | Patient Records → Saved Documents, one diary 📔 with all its entries, which can be viewed, edited and deleted |

In short: use a **report** when each document stands on its own, and a **diary** when the value lies in the sequence of notes over time.

## Step by step

1. Sign in to Beiwe as an **administrator** and open **Settings**.
2. Go to **📋 Document Structures**.
3. In **Document type name** (*Nome do tipo de documento*), type the name (for example, "Session Report" or "Occupational Therapy Assessment").
4. If it is a diary, tick **The document has a diary structure** (*O documento tem estrutura de diário*).
5. Click **Next: Register Sections**.
6. **Step 2 of 2** (*Passo 2 de 2*): type the name of each section and click **Add Section**. For example, for an assessment: "Tactile Processing", "Proprioceptive Processing", "Therapeutic Recommendations".
7. When the list is ready, click **Save Document**.

The document appears in **Registered Document Types and Sections**, and the team can now choose it when writing in **Patient Records → Evolution Reports**.

## After it is created

- You can **rename** the document and **add or remove sections** at any time by opening it in the list.
- The **folder name** is created from the document's first name and does not change afterwards. That folder is where the documents are kept in each patient's record.
